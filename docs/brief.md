# Project Brief — Smart Waste Recycling System

## 1. What Does the System Do?

The Smart Waste Recycling System helps users manage recyclable waste.
Users can submit waste details, request waste pickups, and track their
pickup status. The system can also provide reward points for recycling
eligible waste.

The goal is to make waste collection and recycling more organized,
convenient, and efficient.

## 2. Who Will Use the System?

- **Users:** Register, submit waste details, request pickups, and track status.
- **Collection Staff:** View pickup requests and update collection status.
- **Administrator:** Manage users, waste categories, and pickup records.

- Makes recyclable waste collection easier to organize.
- Helps users track pickup requests.
- Maintains records of waste and collections.
- Encourages recycling through reward points.
